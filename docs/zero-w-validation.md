# Raspberry Pi Zero W 采集性能验证

验证日期：2026-09-12。设备为第一代 Zero W（ARM1176/ARMv6、512 MB 内存），运行 Raspbian 12 Bookworm、Linux 6.12.96。程序使用 Rust 1.93.1、`arm-unknown-linux-musleabihf` 静态 release 构建，连接真实 CC USB 设备，数据库写入本机 SD 卡。

## 历史基线：逐批写入版本

以下是本次缓存/记录速率改造前的结果，不能用作新版验证结果。

### 故障及修复

旧版在 75 秒实机测试中四次报告 `acquisition queue full; capture stopped (data loss)`。每次溢出均明确记录未接受的 800 个样本；已接受数据成功排空。没有发现欠压或内存耗尽的证据。

写入吞吐接近 10 kHz 数据产生速率，SD 卡停顿后积压无法及时消化。修复保留现有数据库结构和 SQLite 同步设置：

- 队列有界扩展至 128 个消息，最多约 10.24 秒 USB 数据。
- 提交时合并现有积压，单次事务最多 32 包。
- SQL 每次插入最多 64 个样本，减少语句执行开销。
- 缓存同一秒的时间戳前缀，保持原有微秒格式及闰秒表示。
- 大批量更新统计时逐包释放共享锁，减少采集线程等待。

### 验证范围

35 项单元测试在本机及 QEMU ARM1176 下通过，覆盖批量写入中途失败回滚、重试后逐样本精度、时间边界、有界积压、保存与会话完整性。check、fmt、Clippy 以及 ARM TUI PTY 测试通过。

优化版的长时间实机测试持续约 320 秒，无队列溢出或自动重启；3,128,800 个已接受样本全部保存。该轮仍记录 14 个 USB 包序号缺口，会话正确标记为 incomplete。此结果不表示所有样本都已收到，也不证明设备测量精度。诊断数据库保留在设备端，不加入仓库。

逐包释放统计锁后的最终安装版本，在 128.5 秒实机测试中保持单一会话：1,282,400 个样本全部保存，零包序号缺口、零队列丢样、无错误，会话为 complete。数据库实际行数与保存计数一致，外键检查通过；运行内存约 12 MB。该有限时长验证不保证所有 SD 卡、系统负载或 USB 连接条件下均不丢包。

最终二进制 SHA256：`27440872c323e3bab39aff57e1c6ac754b5b4b6c6f5ac27acd04cbbef786eb9e`。


## 容量缓存与记录速率版本

### 本地 TUI：默认 10M / 10000 Hz

真实 CC 连续采集 311.12 秒，收到并保存 **3,111,200** 个样本，记录行数和覆盖样本数均为 3,111,200，保留 3,889 个原始帧。包缺口、无效样本、队列丢样均为 0；会话 complete，无错误。SQLite 完整性为 ok，外键检查无错误。

测试过程中切换电压/电流/功率、打开并取消设置、重置显示，最后确认保存。PTY 输出间隔 P95 为 **108.7 ms**，最大 **169.5 ms**；这是终端输出活动间隔，不是电气采样延迟。进程内存峰值 VmHWM 为 **32,212 KiB**，终端设置恢复，退出码 0。

本地运行含最终保存共 **727.53 秒**；确认退出后排空、导入最终数据库和结束操作约需 **416 秒**，最终库为 343,371,776 字节。实时刷新已与写库分离，但 SD 卡上大批量最终保存仍需数分钟，不能把这个等待描述为即时保存。

该轮候选二进制 SHA256：`ec78de6183f32722788fe115a720c679f0b8bc0878238864881e9606ffe03607`。随后仅修正停止后的显示重置、服务状态传输、配置故障状态与导出调度；最终程序另行执行回归验证。

### 调优过程中发现的问题

早期候选版在活动导出与默认逐样本写入并行时出现积压停止，未达到五分钟标准；已接受数据成功排空。不能将这些故障保护测试计为持续采集通过。改造包含紧凑 Client 状态传输，以及让导出以 256 行小批次复制，在每批之间优先让容量写入执行。默认 JSON API 仍可使用。

诊断数据库仅保留在设备端；仓库不包含真实采集数据。所有性能结果仅代表本次设备、SD 卡和负载，不代表测量精度或所有硬件条件。


### 验收范围

本次交付以本机正式构建为准，Zero W 专项调优不作为交付条件，树莓派正式程序未更新。其后测试中，默认速率与 Client 联合运行曾完成 315.6 秒、3,156,000 个样本完整保存，但活动导出超时；取消过严的等待条件后仍出现导出竞争导致的积压停止。最后改为独立低优先级导出线程，该候选轮次提前结束，**未完成最终 Zero W 联合验收**。这些记录不能作为新版在 Zero W 上全面通过的声明。
